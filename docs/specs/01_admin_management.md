# 機能仕様書: 事務局管理（Admin）

## 1. 概要
MESHu プラットフォーム全体の運営・監視・企業審査・代理ログインを行うシステム管理者向け機能群です。
一般ユーザー向け画面とはルーティングおよびセッションが完全に分離されています。

---

## 3. 主要機能仕様

### 3.1. シークレットURLログイン
- 環境変数 `ADMIN_URL_PATH` にてログインURLを可変化（例: `/admin`, `/sys-mgmt` 等）。
- 一般公開URLからのブルートフォース攻撃や不正探索を防止。

### 3.2. 認証バッジ（`company_badges`）発行
- 事務局管理者が企業の実在性・信頼性を確認した際に「認証バッジ」を付与。
- バッジ付与時は改ざん防止用のHMACデジタル署名（`signature`）をDBに記録。
- 認証バッジが付与された企業は、取引先検索画面等で「認証済み」アイコンが表示され、取引の信頼性が高まります。

### 3.3. 代理ログイン機能（Impersonation）
- 問い合わせ対応やトラブルシューティングのため、事務局管理者が任意の企業アカウントとしてワンクリックでログイン可能。
- 代理ログイン中はセッションに `is_impersonating` フラグを保持し、操作監査を担保。
- ユーザー画面上部には代理ログイン中であることを示すバナーが表示され、ワンクリックで事務局管理画面へ復帰可能。

### 3.4. 事務局アクセスIP制限（IP Whitelist）
- 環境変数 `ADMIN_ALLOWED_IPS` に設定されたIPアドレス（カンマ区切り、IPv4 / IPv6 / CIDR範囲指定対応）からのみアクセスを許可。
- 許可外IPからのアクセス時は、事務局画面の存在自体を隠蔽するため **404 Not Found** を返却。
- 未設定または空の場合は制限をスキップ（ローカル開発等の互換性を維持）。
